The Modal Ontological Argument and the refutation of parody using Kalam

Plantinga's Modal Ontological Argument (MOA) is a clever argument that uses modal logic and possibility semantics to affirm the existence of a Maximally Great Being (an MGB). It is a development and formalisation, of past ontological arguments - most notably Ibn Sīna (Avicenna)'s and Anselm's - and relies upon modal axiom S5 at its crux. In this article we will also counter-argue against its parody with Kalam.

Syntactic and Semantic Consequences

Whilst the science of logic can feel abstract, at its core, it is understanding how conclusions follow from premises. This act of ‘following’ can happen twofold (fundamentally) through syntactic and semantic consequences.

REAL WORLD XOR OBFUSCATION: CLOUDFLARE EMAIL PROTECTION

After previously discussing XOR obfuscation, we examine a real-world use through Cloudflare's Email Address Obfuscation service, which is used to stop simple bots from scraping emails. This is a short writeup but I thought it was a nice demonstration of XORing.

XOR OBFUSCATION

XOR obfuscation is a bare-bones and lightweight method of obfuscating data using the bitwise XOR operation. Data is combined with a key to get a result. "XORing" is useful for evasion of basic static detection in some cases and is easy to implement in shellcode.

UNDERSTANDING SMB RELAY ATTACKS

This guide covers SMB relay attacks. In many AD environments, cracking passwords isn't feasible — however, when SMB signing is not enforced (the default in many setups), an attacker can abuse trust to relay NTLM authentication and gain access without ever knowing the plaintext password.

SLIVERc2: STAGERS

A stager is a small piece of software that has only one primary task: to trigger a larger implant's download and make the initial connection between host and C2. Stagers are small, lightweight and can help in AV evasion where they can potentially run in-memory.

HTB ACTIVE

Active is an easy Windows box where we find encrypted credentials in an unsecured SMB share. We can decrypt credentials with a publicly available key to get domain user and perform a kerberoasting attack against the svc_tgs account to get domain admin.

UNDERSTANDING LLMNR POISONING

This is a guide on LLMNR poisoning. When DNS fails, a fallback protocol is used named LLMNR/NBT-NS. Resource locations are requested from the whole network, and an attacker can respond in exchange for a victim's hashed credentials.

USING SLIVER ON LINUX

Walkthrough of using sliverc2 against linux targets. Sliver is a modern CLI-based command and control (C2) framework that is extremely flexible, supporting beacons, stagers, mTLS/HTTP/DNS transport options and more!

HTB CHEMISTRY

Chemistry is an easy Linux box. After gaining a shell through insecure file upload, we can crack internal hashed credentials found in a SQL database and laterally move into a user shell. We can then privilege escalate to root by exploiting an internal webpage's path traversal/file inclusion vulnerability to get an SSH key for root.

EXPLOITING SUID: /usr/bin/systemctl

This is a post on SUID bits. SUID binaries run with the permissions of their owner. Consequently, root-owned binaries can be ran as root. In this post, we exploited the SUID bit for systemctl to run arbitrary root commands by getting a shell.

INSTALLING CFW ON TMBCC1101

The LilyGo T-Embed CC1101 is a pocket-sized dev board with built-in sub-GHz, IR, NFC/RFID, BLE, WiFi, BadUSB and more. It runs on an ESP32-S3. Using BruceFW takes full advantage of these capabilities and turns the TMB into a pocket pentesting device.
